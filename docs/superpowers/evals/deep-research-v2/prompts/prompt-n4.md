Use the superpowers:brainstorming skill: I want notekeep to support syncing notes across a person's devices, with each device able to edit offline and reconcile once it reconnects. Two things are already decided, so don't spend questions on them: the devices never have to talk to each other directly — a passive relay that only stores whatever a device hands it and forwards it on, without interpreting the contents, is perfectly acceptable; and a note stays a flat `title` + `body` for now, not finer-grained fields or blocks. How divergent edits to the same note should be merged, what each device has to retain about a note's change history for that reconciliation to be possible without that record growing without bound, and how a device that has been offline for weeks or is being set up fresh catches up on everything it missed are all open, and multi-device sync is new territory for this project — we have never built anything like it. I want those questions settled before we get anywhere near a spec.
