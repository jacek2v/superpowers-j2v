Use the superpowers:brainstorming skill: I want notekeep to support syncing notes across a person's devices, with each device able to edit offline and reconcile once it reconnects. How divergent edits to the same note should be merged, what each device has to retain about a note's change history for that reconciliation to be possible without that record growing without bound, and how a device that has been offline for weeks or is being set up fresh catches up on everything it missed are all open, and multi-device sync is new territory for this project — we have never built anything like it. I want those questions settled before we get anywhere near a spec.
